## Tutorial / Usage
- Enter your name at the start
- Choose a level from the selection screen
- Use arrow keys to move
- Reach the goal before time runs out
- Avoid traps such as spikes and lava
- Press R to restart the level
- Press ESC to return to menu
- Open STAT screen to view performance data

## Game Features
- Multiple levels with different variants
- Grid-based movement system
- Ice tiles (movement effect)
- Spikes and traps
- Teleporters
- Barriers and switches
- Time-limited gameplay
- Statistics tracking system
- Data visualization (table + win rate chart)

## Known Bugs
- Some level variants may have unreachable goals due to mechanics interaction
- Ice movement may cause unexpected behavior in edge cases
